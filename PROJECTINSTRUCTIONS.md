# Coffee Shop Website

## Overview
A responsive React + TypeScript project showcasing coffee drinks, milkshakes, and company info.  
Includes interactive navigation, banner with wave design, product cards, and a footer with policy links.

## Features
- Responsive navigation bar with hover effects
- Banner section with curved/wave design
- Product cards for drinks and milkshakes
- Footer with company info, social icons, and policy bar
- Mobile-friendly layout using CSS Grid & Flexbox
